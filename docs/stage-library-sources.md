# Stage library sources

The stage library's layouts and briefing text are original, written for this app. These sources were used to learn how real IPSC and USPSA stages and Written Stage Briefings are put together (stage types, round counts, start positions, typical props and procedures). No brief text or diagram was copied. Classic public drills (El Presidente, Bill Drill, Mozambique and similar) keep their well-known names.

The setups use IPSC targets in place of USPSA ones; wording, layouts and the three new stages
(Coffee Break, Off Hand, Box to Box) are original.
